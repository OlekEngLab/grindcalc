GrindCalc — Circular Knife Bevel Calculator

GrindCalc is a web application for calculating the bevel geometry of circular industrial knives and half-knives. It helps users determine grinding geometry, analyze bevel dimensions, and calculate the volume of material removed.

Features

- Part selection: circular knife or half-knife.
- Bevel configuration: single, symmetrical, or asymmetrical bevels.
- Geometric calculations: calculation based on the relevant dimensions of the workpiece and finished part.
- Bevel parameters: definition of bevel angles and dimensions for upper and lower bevels.
- Bevel length calculation: the user enters the length of a right-triangle leg (cathetus), and the application calculates the bevel length along the hypotenuse.
- Material removal: calculation of the volume of material removed during grinding.
- Save calculations: save calculation data for later use.

How to Use

1. Open the application in your web browser.
2. Select the part type and bevel configuration.
3. Enter the required geometric parameters.
4. Specify the bevel dimensions and angles.
5. Review the calculated results.
6. Save the calculation if needed.

Bevel Length Calculation

When defining the bevel geometry, the user enters the length of a right-triangle leg (cathetus). GrindCalc calculates and displays the corresponding hypotenuse, representing the bevel length in the geometric model.

This distinction helps avoid confusing a projected geometric dimension with the actual length of the inclined bevel surface.

Intended Use

GrindCalc is designed for practical engineering calculations related to the geometry of circular industrial knife grinding.

The application provides geometric calculations and estimates the volume of material removed based on the input parameters and the implemented mathematical model.

The results depend on the accuracy of the input data and the assumptions used in the calculations.
